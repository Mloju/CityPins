# City-Pins

## AI-Powered Local Discovery & Social Media Analytics

City-Pins is an AI-powered social media analytics platform that analyzes public Reddit conversations to discover local places, events, and emerging trends.

The project uses social media analytics, NLP, machine learning, and interactive visualization to turn online conversations into useful local insights.
